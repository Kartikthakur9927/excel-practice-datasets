# Excel Practice Datasets - Real-World Problems

This repository contains **real-world, problem-based datasets** designed for Excel practice and skill development. Each dataset comes with real business scenarios and challenges to solve.

## 📊 Datasets Included

### 1. **Sales Performance Analysis** (`sales_data.csv`)
**Scenario**: A retail company wants to analyze sales performance across regions and products.
- **Practice Skills**: VLOOKUP, SUMIF, Pivot Tables, Conditional Formatting
- **Tasks**:
  - Calculate total sales by region
  - Find top-performing products
  - Create sales trend analysis
  - Identify underperforming territories

### 2. **Employee HR Database** (`employee_data.csv`)
**Scenario**: HR department needs to manage and analyze employee information.
- **Practice Skills**: Data Validation, Filters, Advanced Formulas, Pivot Tables
- **Tasks**:
  - Calculate department-wise salary statistics
  - Find employees eligible for promotion (based on tenure)
  - Create age and salary distribution charts
  - Identify high-performers vs. at-risk employees

### 3. **Customer Transaction Log** (`customer_transactions.csv`)
**Scenario**: E-commerce company analyzing customer purchase patterns and RFM segmentation.
- **Practice Skills**: Date Functions, COUNTIFS, INDEX-MATCH, Conditional Logic
- **Tasks**:
  - Segment customers by frequency, recency, and monetary value (RFM Analysis)
  - Identify repeat vs. one-time customers
  - Calculate customer lifetime value
  - Find churn risk customers (no purchase in 6 months)

### 4. **Inventory Management** (`inventory_data.csv`)
**Scenario**: Warehouse manager needs to optimize stock levels and reorder management.
- **Practice Skills**: IF-THEN logic, AVERAGE, SUMPRODUCT, Alerts
- **Tasks**:
  - Flag items below reorder level
  - Calculate inventory turnover ratio
  - Identify slow-moving vs. fast-moving products
  - Estimate reorder quantities

### 5. **Marketing Campaign Performance** (`marketing_campaigns.csv`)
**Scenario**: Marketing team evaluates ROI of multiple campaigns across channels.
- **Practice Skills**: Calculations, % Change, Dashboard Creation, Charts
- **Tasks**:
  - Calculate ROI for each campaign
  - Compare performance across channels
  - Identify most cost-effective campaigns
  - Create budget allocation recommendations

### 6. **Student Grade Analysis** (`student_grades.csv`)
**Scenario**: Educational institution analyzing student performance and progress.
- **Practice Skills**: Weighted Averages, Grade Distribution, Statistical Functions
- **Tasks**:
  - Calculate final grades with weighted scoring
  - Identify struggling students
  - Create performance distribution charts
  - Generate class statistics

### 7. **Project Budget Tracking** (`project_budget.csv`)
**Scenario**: Project manager monitoring budget vs. actual spending across projects.
- **Practice Skills**: Variance Analysis, Conditional Formatting, Trending
- **Tasks**:
  - Calculate budget variance (Actual vs. Planned)
  - Identify budget overruns
  - Create project health dashboard
  - Forecast final project costs

### 8. **Real Estate Sales** (`real_estate_data.csv`)
**Scenario**: Real estate agent analyzing property sales trends and pricing.
- **Practice Skills**: AVERAGEIFS, Statistical Analysis, Visualization
- **Tasks**:
  - Calculate average price by location/property type
  - Identify price trends over time
  - Find properties with best ROI
  - Create market comparison analysis
